元器件选型工具 —— 萨特 + 兴勤 双品牌交付包 (v3.0)
================================

【使用方法】
把这个文件夹里的所有文件解压到同一个目录下，双击打开 萨特选型工具.html 或
兴勤选型工具.html 任意一个，顶部菜单栏可以在两个品牌之间切换。
放到个人网站/服务器时，把文件传到同一目录即可，不需要额外买域名。

【文件说明】

1. 萨特选型工具.html
   萨特(SART)品牌，保险丝(21系列/181型号) + 合金电阻(11系列)

2. 兴勤选型工具.html 【v3.0 完全重做】
   根据用户上传的3份兴勤官方PDF数据手册逐份核对录入，共362个真实型号：
   - TVR压敏电阻：167个型号(Φ5/7/10/14/20mm共5种尺寸)，按本体尺寸+电路
     工作电压(AC/DC)+最小冲击电流筛选
   - SCK NTC(突波抑制型)：130个型号(Φ5~30mm共8种尺寸)，按尺寸+阻值R25+
     电路正常工作电流筛选(重点提醒了"最大稳态电流"这个最容易被忽略的参数)
   - TSM NTC(温度传感型)：65个型号(0201/0402/0603/0805共4种封装)，按封装+
     B值定义(B25/50或B25/85)+阻值R25筛选
   
   之前v2.0版本那53个系列(压敏18+NTC12+PTC11+PPTC12)的估算数据已经全部
   废弃替换，现在只保留这3个有真实规格书数据支撑的系列，数据可信度大幅提升。
   
   规格书下载按钮直接跳转到用户指定的官网产品分类页面：
   - TVR → thinking-cz.com/Products/Metal-Oxide-Varistor.html
   - SCK/TSM → thinking-cz.com/Products/NTC-Thermistor.html

3. 萨特结构化数据.json / 兴勤结构化数据.json
   两个品牌各自的原始结构化数据

【兴勤型号编码说明】
- TVR：型号后缀固定带"K"(唯一的压敏电压公差选项)，实际下单需另外指定外观
  代码(S直脚/F-Y型引脚/T-L型引脚)，工具展示的是不含外观代码的基础型号
- TSM：数据手册原文用□和*作为R25公差、B值公差的占位符，工具展示的是不含
  具体公差代码的基础型号，下单前需按规格书"编码规则"表选择公差代码


【v3.1更新】TSM筛选面板改为精确数值匹配：
- "B值定义"下拉框改成"B值"手动输入框，直接输入具体数字(如3435、3950)精确匹配
- "标称阻值R25"范围输入改成单个手动输入框，支持K简写(如10K、100K、5K)也支持
  不带K的纯数字(如4.7、470，单位KΩ)，精确匹配而非范围筛选


【v3.2更新】三个系列的筛选面板都补齐了缺失的公差/外观/包装选项，现在"开始
选型"生成的是完整可下单型号，不再是缺公差的基础型号：
- TVR：新增"外观"选择(S直脚/F-Y型引脚/T-L型引脚)
- SCK：新增"R25公差"(L/M/N)和"外观"(S/F/T)选择
- TSM：新增"R25公差"(F/G/H/J/K)、"B值公差"(1/2/3)、"包装"(R/B)选择，同时
  按官方编码规则重新精确计算了阻值代码和B值代码(不再用之前简化的数字)，
  已用数据手册里两个真实型号样例(TSMAB103338、TSMAB22444J)核对验证一致

【已知限制】
- 之前提到的PTC热敏电阻、PPTC自恢复保险丝等其他兴勤产品线本版暂未包含，
  只聚焦这3个有实际规格书支撑的系列
- TVR的"外观代码"(直脚/Y型/L型引脚)和TSM的公差代码未做成筛选项，需要
  下单时另行确认
