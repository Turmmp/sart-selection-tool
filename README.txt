萨特(SART)元器件选型工具 —— 交付包说明 (v1.6)
================================

【1】萨特选型工具.html
    - 新增"查看原厂规格书 PDF"功能：保险丝按系列、电阻按系列，筛选结果下方/旁边直接
      给一个链接，点开就是对应系列的原厂PDF数据手册（打包在 datasheets 文件夹里，共32份，
      对应21个保险丝系列+11个电阻系列）。
      ⚠ 重要：datasheets 文件夹必须和 萨特选型工具.html 放在同一目录下（就是解压zip之后
      不要把html单独拎出来用），链接才能正常打开，因为用的是相对路径本地文件链接。
    双击直接用浏览器打开即可使用。本版更新内容：
    - 视觉重做：蓝图蓝主题（工程蓝图配色）替代原来的通用暗色后台风格；
    - 页面顶部加了一条"电阻色环"配色的分隔条作为品牌识别元素；
    - 关键面板用了图纸尺寸标注式的直角边角框；
    - 修复电阻编码模板显示问题：之前直接把 {pkg}/{power} 这种占位符原样显示出来，
      看着像漏了一段代码。现在改成中文标签的分段芯片样式（深色=固定代码，橙色虚线=需要
      按实际选型填入的参数代码），点击可复制原始模板；
    - 移动端适配加固：修复窄屏下头部可能溢出的问题、输入框在iOS上聚焦自动放大
      的问题（改到16px字号规避）、保险丝结果卡片在手机上强制单列显示更好读；
    - 去掉了顶部的"快速搜索"框：这个功能设计逻辑有问题（暗示用户已经知道完整型号
      才能搜，但工具本身是给不知道型号的人用的），属于无效功能，直接移除简化界面；
    - 保险丝筛选新增"额定电压"筛选项。
    - 保险丝结果按系列分组显示（原来是181个型号平铺一坨，现在按系列归类，好找）。
    - 所有型号卡片、电阻编码模板都支持点击一键复制。
    - 交互统一为"填好条件 → 点击开始选型按钮"，避免之前电流输入框改了没反应的问题。
    - 视觉上做了一版工业风深色主题优化：系列分组标题、hover反馈、复制成功提示等。
    - 保险丝：21个系列，共181个真实可下单型号。
    - 合金电阻：11个系列（SME/SMF/SMB/SMD/SMDA/SLT/SMA/SMR/SMS/SMSP/SMSAP）。
    - 数据均逐份核对自SART官方PDF数据手册。
    - 注意：官网产品中心把"1206-FG(8~30A)"误标为"快断车规"，实际数据手册原文是
      Slow Blow(慢熔)，与"1206-FG(40~45A)"系列型号前缀相同但电压不同(50V/35V)，
      下单前务必让业务员书面确认型号后缀。

【2】萨特结构化数据.json
    工具背后的原始结构化数据（JSON格式），如果以后要换开发框架、接数据库，
    直接读这份文件就行，不用重新从PDF提取。

【3】sart_manual_crawler.py
    之前写的爬虫脚本，用于从萨特官网下载"选型手册"图片版PDF页面，供后续
    有新品类/新版本手册时重新抓取使用。
    用法：pip install requests beautifulsoup4 img2pdf 后运行 python sart_manual_crawler.py

    - 修复"查看原厂规格书PDF"点击没反应的问题：Chrome等浏览器对本地html页面用
      target="_blank"打开另一个本地文件有静默拦截机制（不报错，就是没反应）。现在改成
      当前页跳转打开PDF，看完PDF用浏览器"后退"按钮回到选型工具即可。

    - "查看原厂规格书PDF"链接改为萨特官网原始下载地址（不再指向本地datasheets文件夹），
      点击直接跳转官网下载PDF。这样一来 萨特选型工具.html 这一个文件就能独立分享给任何人
      使用，不用再带着文件夹、不用担心链接失效。
      注：datasheets文件夹仍然保留在这个交付包里，作为离线备份（万一官网哪天改版链接失效，
      本地还有一份原件），但工具本身运行不再依赖它。

    - 修复"前往萨特官网下载规格书"链接403 Forbidden的问题：萨特文档服务器对PDF直链设置了
      防盗链(Referer ACL)，外部页面没法直接跳转PDF文件本身，一律403拒绝。现在改成链接到
      该系列在萨特官网的产品详情页，用户在官网页面内自己点下载，绕开防盗链限制，同时依然
      不依赖本地文件，工具单个html文件分享给任何人都能用。

    - 规格书链接改回"新标签页打开"（target="_blank"），不再覆盖当前的选型工具页面，
      点击后官网产品页在新窗口/新标签页打开，选型工具这边保持不动，方便来回切换查看。

    - 规格书链接改回新标签页打开，不覆盖工具页面。
    - 新增"客户实际电流裕量计算器"：保险丝筛选面板顶部新增一栏，输入客户实际电流，
      自动算出常规场景(1.5倍)和高温/冲击电流场景(2倍)两档建议选型电流，点"应用"直接
      填入下方的额定电流筛选条件，不用同事再手动心算1.5倍。

    - 裕量计算器挪到结果区下方，改成纯参考小工具：输入客户电流，显示1.5倍/2倍两档建议，
      不会再自动覆盖上面已经筛选出来的型号列表，同事自己看着数字手动填筛选框即可。
    - 确认"前往萨特官网下载规格书"按钮为新标签页打开(target="_blank")，不会覆盖工具页面。

    - 规格书链接改用 window.open() 显式调用打开新窗口，替代纯href target="_blank"属性方式，
      提升在不同浏览器/环境下的兼容性。
